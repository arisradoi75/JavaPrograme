# Java University Exercises

This repository contains the Java exercises I completed during the semester for my university course. Each folder or file represents a different topic, assignment, or practice task covered throughout the class. The goal of this repo is to keep all coursework organized and easy to review.

## What You'll Find Here

* Solutions to weekly lab exercises
* Practice programs written during lectures
* Small projects assigned throughout the semester
* Experiments and additional code used for learning

## Purpose

This repository serves as a personal archive of my progress in learning Java at university. It includes all the exercises I worked on during the semester, demonstrating both the concepts covered in class and my practical understanding of them.

Feel free to explore the code! If you have suggestions or improvements, you're welcome to open an issue or contribute.
